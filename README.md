## 订阅还是永久？三档授权时长怎么选

Navicat 官网的定价逻辑是永久授权自带 1 年软件维护，这 1 年里可以免费升级到新版本，也能用在线客服和技术支持、申请 key 重置。第 2 年开始想继续拿大版本升级和技术支持，得另外续维护费；不续的话，软件照常能用，只是停留在你买到的那一版，新出的大版本升不了。

所以订阅和永久的选择，本质上是在赌你会用多久：

- 项目周期三个月以内，或者只是临时接一个库看看结构，3 个月订阅最干脆，用完就结束，不占用后面的预算。
- 一年内能收尾的项目、外包交付、临时支援，买 1 年订阅。
- 打算长期把这套工具当成日常主力，直接上永久授权。用满两年左右，累计支出就开始低于连续订阅，之后每多用一个版本都是净赚。

多人采购的话，Navicat 官网对永久授权有阶梯折扣，5 到 9 套打 85 折，10 套以上 8 折，这个折扣是按许可证数量算的。团队买之前值得问一下经销商能不能申请同等折扣，按人头买三五套的时候差价不小。

## 按你的情况选：谁该买哪个

**在校学生和教师**，先查非商业版的资质要求。Navicat 有专门的教育与非营利授权，价格明显低于商业版，代价是只能用于学习、教学和非营利项目，拿去做商业项目属于违规。符合条件的话没必要多花那份钱，这是个实打实的省钱点。👉 [确认自己是否符合非商业版条件](https://lizhi.shop/products/navicat-premium?cid=7bbix2xj)

**只连一个数据库的人**，先别急着买 Premium。Navicat 有按单库拆分的版本，Navicat for MySQL、for PostgreSQL、for SQL Server、for Oracle 各自独立销售，功能聚焦在一个库上，价格比 Premium 低。判断标准很简单：你需要的数据库类型超过两种，或者其中包含 Oracle、SQL Server 这类高价库并且还要再连一个别的，Premium 才开始比买两套单库版便宜。只连 MySQL 一个库，买 Premium 是浪费。

**个人开发者和小团队**，标准版永久授权是最优解。日常开发用不到建模和 BI，把钱花在全库连接上更实在。

**需要交付数据模型或报表的团队**，企业版。ER 图和 BI 看板不是能凑合的东西，自己拿别的工具拼出来的图，交付给客户时的观感和维护成本都差一截。

**只想偶尔连库看看数据的人**，这类需求我不建议买付费版。免费的 Navicat Premium Lite 或者别的开源客户端完全够用，为一个每月打开两次的工具付几百上千，不划算。

## 用起来怎么样，有哪些真实的槽点

Navicat Premium 在开发者圈子里的口碑整体不错。G2 上有用户评价说，它让跨多个数据库和环境的工作变简单了，比自己试过的其他工具和开源工具都好用。这个评价抓住了它的核心价值：一套界面、一套快捷键、一套连接管理，切换 MySQL 和 PostgreSQL 不用换脑子。

槽点也集中：

**永久授权的一次性支出不低**，尤其企业版，对个人开发者是一笔要认真考虑的投入。而且它只含 1 年维护，第 2 年想继续升大版本还得再掏维护费，这部分成本买的时候容易忽略。

**授权按用户计**，官网商店页明确写的是 per user base。团队里三个人要用就买三套，不能一套装三台电脑给三个人分工用。

**非商业版有资质门槛**，审核不过就得回头买商业版，别先斩后奏。

**Lite 版砍的功能偏运维**，如果你需要定期备份数据库、或者要从 Excel 批量导入数据，免费版会卡在这里。

拿到激活码后在 Navicat 里输入激活，跨平台授权可以在 Windows、macOS、Linux 之间切换，一个 key 对应一个平台使用。

## 常见问题

**数码荔枝卖的 Navicat 是正版吗？**

数码荔枝是 PremiumSoft 的授权经销商，卖的是中国区正规渠道的激活码，不是灰产渠道。激活码可以在 Navicat 官网验证真伪。

**一个授权能装几台电脑？**

授权按用户计，一位使用者一个授权。同一个人换电脑或者换操作系统可以迁移，具体迁移规则看 Navicat 官方的授权说明。

**永久版以后升级新版本要另付钱吗？**

永久授权含 1 年软件维护，这一年内的新版本免费升级。第 2 年起要继续获得升级和技术支持需要续维护费，不续也能一直用当前版本。

**Navicat Premium 和单独买 for MySQL 有什么区别？**

Premium 一套客户端连所有支持的数据库，单库版只连一个。需要两种以上数据库时 Premium 更划算，只用一种时单库版更便宜。

**买错了版本能换吗？**

下单前把版本和授权时长核对两遍。虚拟商品的授权一旦发出，退换通常有严格限制，付款前那一步是唯一的纠错机会。
